# Chiang Rai SmartTrip – AI-Powered Local Tourism Planner

เว็บแอปพลิเคชันจัดทริปเที่ยวเชียงราย 1 วันแบบอัตโนมัติ ออกแบบมาเพื่อแก้ปัญหาให้นักท่องเที่ยวที่ต้องการเดินทางเที่ยวในจังหวัดเชียงรายให้คุ้มค่าที่สุด โดยไม่สะดุดกับเวลาเปิด-ปิด สภาพอากาศ (เช่น ฝนตก) หรืองบประมาณที่จำกัด

## ฟีเจอร์ที่ผ่านการทดสอบและใช้งานได้จริง (Verified Features)
1. **เชื่อมต่อ Dataset จริงของผู้จัด:** ดึงข้อมูลจาก `Chiang_Rai_SmartTrip_Competition_Dataset.xlsx` ครบทั้ง 3 Sheets (Attractions 10 แห่ง, Matrix 10x10, Rules & Sources)
2. **Form & Dynamic Validation:** รับค่าความสนใจ (เลือกได้หลายหมวด), งบประมาณ, ระยะเวลา, เวลาเริ่มเดินทาง, สภาพอากาศ และจำนวนคน พร้อมข้อความเตือนภาษาไทยเมื่อกรอกผิด
3. **Route Optimization & Matrix Engine:** คำนวณเส้นทางเริ่มจากหอนาฬิกาเชียงราย (F) เสมอ, คำนวณเวลาเดินทางด้วย Travel Time Matrix จริง, แสดงเวลารอเปิด และควบคุมไม่ให้เกินเวลาปิดทำการ
4. **Weather Adaptation:** เมื่อเลือกสภาพอากาศเป็น Rain (ฝนตก) ระบบจะตัดสถานที่ Outdoor ทั้งหมดออกทันที และคัดเลือกเฉพาะสถานที่ในร่ม (Indoor) หรือพื้นที่ผสม (Mixed)
5. **สรุปงบประมาณชัดเจน:** คำนวณค่าใช้จ่ายต่อคนและรวมทั้งกลุ่ม แสดงเงินคงเหลือและแถบเปอร์เซ็นต์การใช้งบประมาณ
6. **Explainable AI Insights:** อธิบายเหตุผลเบื้องหลังการเลือกเส้นทาง 4 มิติอย่างตรงไปตรงมา พร้อมคะแนนความคุ้มค่า Smart Trip Score
7. **4 ทริปตัวอย่าง (Presets):** ปุ่มลัดสาธิต 4 สถานการณ์ (ธรรมชาติและไร่ชา, หลบฝนในร่ม, สายประหยัด ฿50, อาหารยามเย็น)
8. **Dynamic Trip Comparison:** แถบเปรียบเทียบผลลัพธ์กับแผนก่อนหน้าแบบเรียลไทม์ (จำนวนสถานที่, เงินที่ประหยัดได้, เวลาที่เปลี่ยนไป)
9. **เครื่องมือพิมพ์และตรวจสอบข้อมูล:** ปุ่มพิมพ์แผนเที่ยว/บันทึก PDF, ปุ่มคัดลอกลงคลิปบอร์ด, หน้าต่างตรวจดูตารางข้อมูล และระบบนำเข้า Dataset แบบกำหนดเอง

## ข้อจำกัดในเวอร์ชันนี้ (Limitations)
- ออกแบบมาสำหรับการจัดทริป 1 วัน (สูงสุด 24 ชั่วโมง) ยังไม่รองรับการค้างคืนหลายวัน
- คิดค่าใช้จ่ายเฉพาะค่าเข้าชมสถานที่ตามโจทย์กำหนด ยังไม่รวมค่าเดินทางหรือค่ายานพาหนะ

## สรุปการใช้ AI
ทีมงานใช้ AI (Antigravity - Gemini 3.8 Flash High) ช่วยแปลง Dataset จากไฟล์ Excel พัฒนาอัลกอริทึม Pruned Search จัดเส้นทาง ตรวจสอบเงื่อนไขการแข่งขัน และจัดทำ UI/UX สไตล์ Lanna Dashboard ดูรายละเอียดประวัติคำสั่งและการตรวจรับงานทั้งหมดได้ที่ [AI_LOG.md](AI_LOG.md)
